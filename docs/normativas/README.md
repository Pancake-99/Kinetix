# Normativas

Checklists y evidencias de cumplimiento de estándares.

| Estándar | Alcance | Archivo sugerido |
|---|---|---|
| ISO/IEC 25010 | Calidad del producto software | `checklist-iso-25010.md` |
| ISO 9001 | Gestión de la calidad del proceso | `checklist-iso-9001.md` |
| ISO/IEC 27001 | Seguridad de la información | `checklist-iso-27001.md` |

Cada checklist debe registrar: criterio evaluado, estado (cumple / parcial / no cumple),
evidencia (enlace a código, prueba o documento) y responsable.
