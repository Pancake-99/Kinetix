# Trazabilidad

Matrices de trazabilidad entre entrevistas, requisitos (SRS), diseño y pruebas.

## Contenido sugerido

- `matriz-trazabilidad.md` — Tabla que vincula cada requisito (`RF-<n>` /
  `RNF-<n>`) con su origen (entrevista), su diseño (modelos/diagramas) y sus
  pruebas de verificación (`tests/`).

## Convención de nombres

`matriz-trazabilidad-v<version>.md`
