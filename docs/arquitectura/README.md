# Arquitectura

Documentación de decisiones y vistas de arquitectura del sistema.

## Contenido sugerido

- `decisiones/` — Registros de decisiones de arquitectura (ADR), un archivo por
  decisión: `NNNN-titulo-decision.md`.
- `vistas.md` — Descripción de las vistas arquitectónicas (lógica, de
  despliegue, de datos) con enlaces a los diagramas C4 en
  [modelos/c4](../../modelos/c4/).
