# Actas

Acta de constitución del proyecto y minutas de reunión.

## Convención de nombres

- Acta de constitución: `acta-constitucion.md`
- Minutas: `YYYY-MM-DD-minuta-<tema>.md`

## Contenido mínimo de una minuta

1. Fecha, hora y modalidad.
2. Asistentes y ausentes.
3. Temas tratados.
4. Acuerdos tomados.
5. Compromisos: tarea, responsable y fecha límite.
