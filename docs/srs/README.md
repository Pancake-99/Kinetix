# SRS (Software Requirements Specification)

Especificación de requisitos de software del proyecto.

## Contenido sugerido

- `srs.md` — Documento maestro (introducción, alcance, requisitos funcionales y
  no funcionales, restricciones).
- Requisitos funcionales identificados con `RF-<n>` y no funcionales con
  `RNF-<n>` para poder referenciarlos desde [trazabilidad](../trazabilidad/).

## Convención de nombres

`srs-v<version>.md` — por ejemplo `srs-v1.0.md`.
