# Modelo C4

Diagramas de arquitectura siguiendo el modelo C4 (Contexto, Contenedores,
Componentes, Código).

## Formato

Se versiona el **fuente** del diagrama (`.puml`, `.mmd` o `.drawio`) junto con
la imagen exportada (`.png` / `.svg`). El fuente es la referencia; la imagen es
solo para lectura rápida en el navegador de GitHub.

## Convención de nombres

`c4-<nivel>-<nombre>.puml` — por ejemplo `c4-contexto-sistema.puml`,
`c4-contenedores-kinetix.puml`, `c4-componentes-servidor.puml`.
