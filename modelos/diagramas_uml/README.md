# Diagramas UML

Diagramas de casos de uso, clases y actividades.

## Formato

Se versiona el **fuente** del diagrama (`.puml`, `.mmd` o `.drawio`) junto con la
imagen exportada (`.png` / `.svg`). El fuente es la referencia; la imagen es solo
para lectura rápida en el navegador de GitHub.

## Convención de nombres

`<tipo>-<nombre>.puml` — por ejemplo `casos-uso-autenticacion.puml`,
`clases-dominio.puml`, `actividades-registro-usuario.puml`.
